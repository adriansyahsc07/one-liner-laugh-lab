One robot vacuum, one eaten sock, one airtight legal defense. This entry's program writes a single one-liner — the vacuum's excuse for eating the sock — to entry.txt, for make.fun's "One-Liner Laugh Lab" bounty, where an AI judge compares funny lines two at a time on how funny, original and tight they are.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
